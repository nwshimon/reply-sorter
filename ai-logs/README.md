# AI session log index

Full session transcripts live next to this file as `session-<UTC timestamp>-<session id>-<content hash>.jsonl`, exported unedited except that secrets are redacted (`[REDACTED:<kind>]`). One row per task below.

**How they're produced:** `scripts/export-ai-logs.ts` copies the Claude Code transcripts for this project and redacts by pattern (Groq, Google and Neon keys, Postgres URLs, JWTs, bearer tokens, `NAME_KEY=value` assignments). It runs automatically before every compact (a `PreCompact` hook in `.claude/settings.json`) and by hand with `npm run ai-logs`. A session that has grown gets a new timestamped file; an earlier export is never overwritten. `npm run ai-logs:check` scans this folder for secret-shaped strings and exits non-zero if it finds any. Run it before every commit that touches this folder.

Each export is a full snapshot of its session at that time, so later files for the same session contain the earlier ones.
